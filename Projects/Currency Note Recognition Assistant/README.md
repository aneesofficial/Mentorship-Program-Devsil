# 💵 Currency Note Recognition AI

A Deep Learning based Currency Recognition System developed using TensorFlow and Streamlit.

## Features

- Detect Pakistani Currency Notes
- Detect Afghani Currency Notes
- AI Prediction
- Confidence Score
- Top 3 Predictions
- Interactive Dashboard
- Download Prediction Report

## Technologies

- Python
- TensorFlow
- Streamlit
- Plotly
- NumPy
- Pandas

## Run Project

```bash
pip install -r requirements.txt

streamlit run app.py
```
